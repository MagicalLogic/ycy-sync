## 项目介绍

这是「异次元」Android 客户端的一个修改版，重点补充官方版缺失的**自动多设备进度同步能力**，并修复一批影响阅读和书架使用的稳定性问题。

修改版不修改官方服务器，也不提供漫画内容，只负责：

- 通过用户自己的 WebDAV 同步书架、分组、阅读进度
- 修复书架刷新、备份、下载阅读等流程中的卡死与异常
- 提供应用内更新提示，方便从旧版升级

本仓库用于存放：

- 版本更新信息 `update.json`
- GitHub Release 安装包
- 版本说明与下载入口

不包含官方源码，也不分发漫画资源。

## 主要功能

### 云同步

- 填写 WebDAV 后自动同步书架、分组、阅读进度
- 多设备之间无感续读
- 支持手动上传/恢复
- 云同步不包含已下载的漫画文件

### 性能与稳定性

- 备份不再逐本加载章节，1000 本约 0.4–0.6 秒
- 书架列表不再逐本加载章节，1000 本约 3 秒显示
- 修复书架刷新停在最初几本、后续书无法进入刷新队列
- 单本刷新 15 秒超时，失败不阻塞后续书
- 恢复备份后自动补章节，修复 `CHAPTER_URL` 为空
- 修复下载列表进入已下载章节时卡读取

### 阅读器

- 新增“预加载下一页”开关，减少点击翻页黑屏
- 新增“翻页动画速度”：0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x
- 保留原版左右翻页、上下滚动
- 修复点击翻页与滑动翻页交替时的部分异常
- 修复云端进度提示在页面关闭后可能崩溃

### 更新提示

- 启动时检查新版本，24 小时最多一次
- 三按钮：立即更新 / 稍后 / 忽略此版本
- 立即更新可选 GitHub Release 或蓝奏云
- 设置 → 新增功能 → 更新设置：
  - 立即检查
  - 不提示更新 / 开启更新提示
  - 清除已忽略版本
  - 查看当前版本
- 不强制更新

### 其它

- 应用内更新公告
- 移除自定义翻页动画，恢复原版翻页效果
- 修复部分图源 `@Header`、图片 http/https 问题

## 安装与升级

### 首次安装

1. 下载 `ycy-sync-v1029.apk`
2. 允许安装未知来源应用
3. 安装后打开，按提示授予存储权限

### 从旧版升级

- 直接覆盖安装即可，数据保留
- 不要先卸载，否则本地书架和阅读进度会丢失

### 从官方版迁移

1. 官方版先做备份
2. 修改版恢复该备份
3. 重新填写 WebDAV 账号
4. 等待自动补章节完成

### 降级

- 不建议降级
- 降级通常需要卸载，会丢失本地数据
- 降级前先做备份

## 注意事项

1. **非官方版本**：与官方团队无关，不代表官方立场。
2. **仅供学习交流**：请在下载后 24 小时内删除，不得用于商业用途。
3. **不要用于传播盗版**：本项目不提供漫画内容，不同步漫画文件。
4. **数据安全**：升级、降级、换机前先备份；WebDAV 账号密码请自行保管。
5. **云同步不含下载文件**：已下载漫画不会上传到 WebDAV。
6. **恢复备份后需要补章节**：首次打开书架会自动补，可能需要等待。
7. **刷新失败与网络有关**：失败率受图源、节点、并发影响，失败后可重试。
8. **仅刷新当前分组**：不会一次刷新全部书架。
9. **更新提示不强制**：可以忽略某个版本，或在设置中关闭提示。
10. **蓝奏云为备用源**：GitHub 打不开时使用；提取码以弹窗显示为准。
11. **不要使用二次打包版本**：可能被植入恶意代码或被修改签名。
12. **系统要求**：Android 5.0 及以上；部分 ROM 需要手动允许后台联网。

## 数据与隐私

- WebDAV 地址、账号、密码只保存在本机
- 同步数据直接发送到用户自己的 WebDAV，不经过本项目服务器
- 更新检查只请求 `update.json`，不上传任何用户数据
- 本项目没有自有服务器，也不收集用户信息
